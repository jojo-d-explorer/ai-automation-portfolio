# Deprecated one-click prompts

This directory holds historical Cowork prompts that have been superseded by
newer versions. Files here are kept for reference only — do NOT run them.

When archiving, use the format:
  ONE_CLICK_<version>_archived_<YYYY-MM-DD>.md

Active prompts live one level up in `one_clicks/`. The current active version
is documented in `specs/WORKFLOW_*.md` (latest spec version).
